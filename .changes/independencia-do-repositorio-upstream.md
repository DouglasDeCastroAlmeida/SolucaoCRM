titulo: Imagens, instalação e publicação passam a depender só do repositório do dono
---

As imagens, o instalador, o atualizador e a publicação das versões passam a apontar para o repositório do dono do produto, sem nenhuma dependência do repositório de origem. O `update.sh` leva as instalações existentes para as imagens novas sozinho, sem edição de arquivo. A publicação de uma versão agora é feita em dois passos manuais no GitHub (corte da versão e publicação da versão). Nenhuma tela, rota, tabela ou configuração mudou.
